# 🏛️ ТРИДЕВЯТОЕ ЦАРСТВО СИНЕЙ БЕРЕСТЫ [Whitepaper_V1_Core]
> **Суверенная Web3-Инфраструктура, Децентрализованный Финтех и P2P-Мессенджер Локальных Нод Бояр на стыке Telegram WebApp, Node.js/C++ и Локального ИИ.**

---

## 📜 1. МАНИФЕСТ И ГЕНЕРАЛЬНЫЙ ПЛАН СИСТЕМЫ

Современный цифровой мир (Web2) заперт в корпоративных засеках. Монополии Apple, Google и централизованные облачные сервера полностью уничтожили суверенитет личности. Цензура, тотальное логгирование приватных данных и удушающие финтех-поборы в 30% (AppleTax) блокируют развитие независимых общин и свободных инженеров.

**Тридевятое Царство** — это технологический ответ шифропанков. Мы не строими сайт или мобильное приложение в привычном понимании, которые можно заблокировать или удалить из App Store. Мы разворачиваем децентрализованную P2P-сеть автономных **Домашних Нод Бояр**, запечённых в единый блокчейн-реестр (Летопись) Синей Бересты. 

(«Синяя Береста» — это суверенное технологическое имя нашего Портала, означающее зашифрованный, помехоустойчивый сетевой слой, где берестяные грамоты сообщений наносекундно переплавляются в нестираемые блоки распределённой Летописи).

Telegram используется нами исключительно как **бесплатный, неуязвимый фронтенд-транзитер (гейт)** через технологию WebApp. Настоящий «ум» системы, базы данных (PocketDb) и криптографические ключи хранятся и обрабатываются локально на оборудовании участников общины.

Полноэкранный терминал Синего Вестника — это не просто хай-тек рация, это цифровое Волшебство и ожившая древняя Легенда. Каждое нажатие на бересту, Кон Приколов ИИ-Скомороха или безвозвратное сжигание Янтаря в Берёзовом Роднике Оракула Яги переводят древние Коны Общины на язык программного кода. Мы возвращаем Память Рода сквозь кремниевые кристаллы, взводя лазерные межи Чертогов Числобога на защиту суверенной экономики Бояр. Наш блокчейн — это вечный Свиток Славы, где каждая raw-транзакция становится нестираемой летописью Игрищ и Труда сородичей, превращая партизанский сокет-мост в нерушимый цифровой оплот Тридевятого Царства.

## ⚙️ 2. АРХИТЕКТУРА И СЕТЕВАЯ ИЗОЛЯЦИЯ TRAFFIC CORE

Инфраструктура Цифрового Царства базируется на полной изоляции данных от внешнего Web2-шума и распределении нагрузки по Родовым портам связи:

*   **Порт `8027` [P2P_Message_Vessel]:** Выделенный сетевой контур для наносекундной маршрутизации и транзита зашифрованных текстовых сообщений (берестяных дум) между Зеркальцами Странников. Оборудован асинхронной микро-очередью пакетов `[P2P_Queue_Lada]` с шагом 40 мс для предотвращения сетевых фризов.
*   **Порт `8028` [RPC_Smart_Contracts]:** Суверенный RPC-шлюз для обработки команд смарт-контрактов, вызова финтех-методов ядра и управления Ларцами Казны. 
*   **Пробитие NAT [coturn_cluster]:** Для преодоления ограничений мобильных провайдеров и Прямой связи нод «Боярин-к-Боярину» развёрнут кластер TURN/STUN-серверов связи на базе утилиты `coturn`, связывающий стартовые 10 фрактальных нод в неделимый кворум.

## 🔑 3. КРИПТОГРАФИЧЕСКИЙ ПРОТОКОЛ [Telegram_Auth_Bridge]

Вход из тумана на Родовую Поляну Тридевятого Царства полностью децентрализован и безопасен:
1. При первом клике Странника по кнопке в Telegram-боте, встроенный микросервис `beresta-bridge` перехватывает нативную SHA-256 хэш-строку авторизации WebApp.
2. Эта строка передаётся в локальную песочницу устройства получателя для мгновенной отработки Протокола **`[Local_Key_Genesis]`**.
3. На основе хэша генерируется суверенная пара приватных ключей по стандарту **Ed25519**. Логгирование, хранение или передача приватных ключей на внешние серверы мессенджера запрещены на уровне ядра.
4. При успешном генезисе профиля бэкенд возвращает статус **`Identity_Locked`**, открывая Страннику допуск сквозного оверлея Зеркальца (слой `z-50`).

## 🧮 4. СУВЕРЕННЫЙ ФИНТЕХ И АНТИ-МОНОПОЛЬНЫЙ КОНТУР

Финансовая система Тридевятого Царства построена на 7 Истинных Балансах Казны (Янтарь YNT, Искорки Зари, Тропы Богов Велеса, Перуна, Сварога) и полностью обнуляет Web2-поборы:

*   **Метод `AppleTax` 27% [Artel_Fintech_Tax_Gate]:** Вместо грабительских 30% корпораций, встроенный интерактивный калькулятор Кузницы автоматически рассчитывает налог в **27% YNT**, который уходит не посредникам, а безвозвратно запекается в Пулы Валидаторов и Казну Общины для развития Леса.
*   **Движок Веса Голоса [Veche_Vote_Weight_Engine]:** Сила клика на Всемирном Вече (Фон 7) при принятии решений рассчитывается динамически на основе Чина Странника (Странник x1.0, Боярин x1.5, Кудесник x2.0) и накопленного Света с Тропы Перуна. Множитель Зодчего Вырия (x2.0) накладывается поверх Чина.
*   **Зарок Вепря (P2P-Вето):** При активации Боярского Вето Бунта (Фон 5), система запускает блокчейн-заморозку 40 Янтарей (40 YNT), аппаратно блокируя ключи нарушителей Кона.

## 🧠 5. ИИ-АНСАМБЛЬ ЛОКАЛЬНЫХ МОДЕЛЕЙ [ai_engine.h]

Умная экосистема Тридевятого Царства не зависит от OpenAI или Google Gemini. Весь искусственный интеллект разворачивается на видеокартах самих Бояр:
*   **Контейнеризация:** ИИ-движок упакован в монолитный `docker-compose.yml` и работает через легковесный сервер `llama-server`.
*   **Нейросетевое Ядро:** Квантованные веса модели **`mistral-7b-q4_k_m.gguf`** через среду `llama.cpp` удерживают ЛОР-контекст в `2048` токенов, исключая галлюцинации.
*   **GPU Пасстру:** Контур жестко требует через NVIDIA Container Toolkit выделения минимум 6 ГБ изолированной VRAM под поток Серого Волка. При нехватке памяти контейнер автоматически стопорится, предотвращая краш ОС.
*   **ИИ-Агенты:** В шапках чатов интегрированы живые RPC-методы вызова Агентов: Скоморох (Фон 3, Кон Приколов), Дворецкий (Фон 5), Елена Премудрая (Фон 7), Баба Яга (Фон 9, метод сжигания 1 YNT `Birch_Spring_Flow` для Навьего Hard Reset памяти).

## 🛠️ 6. РУКОВОДСТВО ПО ЛОКАЛЬНОМУ РАЗВЁРТЫВАНИЮ ФРОНТЕНДА
Для локального запуска суверенного Зеркальца на порту `5173`:

```bash
# 1. Клонировать репозиторий Тридевятого Царства
git clone https://github.com

# 2. Войти в директорию фронтенда
cd beresta-front

# 3. Установить зависимости ядра (включая Tailwind v4 и PostCSS)
npm install

# 4. Запустить боевой esbuild-сервер с очисткой кэша
npm run dev -- --force
```
